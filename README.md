# Лаборатори №1 — UI автомат тест (Playwright)

**Хичээл:** F.CSA313 — Программ хангамжийн чанарын баталгаа ба тест

## Зорилго

Playwright ашиглан веб сайтын UI үйлдлүүдийг автоматжуулж, assertion, Codegen, HTML Report болон Trace Viewer хэрэгслүүдийг турших.

## Ашигласан технологи

- Node.js v20.17.0
- Playwright Test
- TypeScript
- Chromium
- Visual Studio Code
- Git / GitHub
- Туршилтын сайт: https://www.saucedemo.com/

## Гүйцэтгэсэн ажлууд

`tests/mytest.spec.ts` файлд хоорондоо хамааралгүй дараах гурван тестийг бичсэн.

1. **Амжилттай нэвтрэх:** Зөв хэрэглэгчийн мэдээллээр нэвтэрч, Products хуудас нээгдсэнийг шалгаад Logout хийсэн.
2. **Буруу нууц үгээр нэвтрэх:** Буруу нууц үг оруулахад алдааны мэдэгдэл гарч байгааг шалгасан.
3. **Барааг сагсанд нэмэх:** Нэвтэрч, Sauce Labs Backpack барааг сагсанд нэмэн, сагсны тоо болон барааны нэрийг шалгаад Logout хийсэн.

Тестүүдэд `getByRole`, `getByPlaceholder`, `getByText`, `locator` болон `expect` ашигласан.

## Тест ажиллуулах

Төслийн шаардлагатай сангуудыг суулгах:

```bash
npm install
npx playwright install
```

Бүх тестийг ажиллуулах:

```bash
npx playwright test
```

Үндсэн гурван тестийг Chromium дээр Trace-тай ажиллуулах:

```bash
npx playwright test tests/mytest.spec.ts --project=chromium --trace on
```

HTML тайланг нээх:

```bash
npx playwright show-report
```

## Codegen ба Trace Viewer

## Playwright ба Selenium-ийн харьцуулалт

Playwright болон Selenium хоёулаа веб интерфейсийн автомат тест хийхэд ашиглагддаг нээлттэй эхийн хэрэгслүүд юм. Selenium нь олон жилийн турш хэрэглэгдсэн бөгөөд олон програмчлалын хэлийг дэмждэг. Playwright нь браузер суулгах болон тест ажиллуулах нэгдсэн хэрэгслүүдтэй тул анхны тохиргоо хийхэд ойлгомжтой санагдсан. Playwright-ийн auto-wait боломж нь элемент бэлэн болохыг автоматаар хүлээдэг учраас нэмэлт хүлээлтийн код бичих шаардлагыг багасгадаг. Selenium дээр зарим нөхцөлд explicit wait тохируулах хэрэг гардаг. Playwright-ийн Codegen нь хэрэглэгчийн үйлдлээс тестийн код үүсгэдэг бол Trace Viewer нь алдаа гарсан алхмыг дэлгэрэнгүй судлах боломж олгодог. `getByRole` зэрэг утгад суурилсан locator нь элементийн бүтэц өөрчлөгдөхөд эвдрэх эрсдэлийг бууруулдаг тул XPath-аас аль болох зайлсхийх нь тохиромжтой гэж үзсэн. Энэ лабораторийн хувьд Playwright-ийг суулгах, тест бичих, ажиллуулах, алдаа шинжлэх үйл явц нь нэг дор төвлөрсөн давуу талтай байлаа.

## Дүгнэлт

Энэ лабораторийн ажлаар Playwright төсөл үүсгэж, SauceDemo сайтын үндсэн үйлдлүүдийг автоматжуулсан гурван тест бичсэн. Тестүүдийг тус тусад нь болон хамтад нь ажиллуулж шалгасан. Codegen, HTML Report, Trace Viewer ашиглан тестийн үр дүнг баримтжуулсан. Мөн assertion-ийг санаатай буруу болгож, алдааны шалтгааныг Trace Viewer-ээр тодорхойлсон. Үүний үр дүнд UI автомат тест бичих, шалгах болон дебаг хийх үндсэн дадлага эзэмшсэн.
